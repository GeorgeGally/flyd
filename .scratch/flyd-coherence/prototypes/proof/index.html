How Flyd shows finished work.

A proof is one point made like a presentation slide: the change, cropped to where it happened, before and after at the same size, with one line of why. Two real examples, three ways to show them.

What a proof holds

The point

One sentence about what is different for the person using it. Not what the code did.

Before and after

The same crop of the real page, at the same scale. One drawn mark per change.

Why

One line. When it answers your note, your words come first.

Where

A tiny whole page with the crop boxed, which opens the live thing at that spot.

Next

What Flyd does next. Stated, not asked. You can change it.

How Flyd picks the crop

  1. The changed element plus one neighbour, so you can tell where you are: the card beside it, the heading above it.
  2. The same rectangle before and after, so the only thing that moves is the change.
  3. If the change is about position, the crop includes what it is measured against, and Flyd draws it: the grid column, the screen's middle, the frame's edge.
  4. If the change is about where something sits on the screen, keep the full height and crop only the sides.
  5. Shown at the device's own shape. Phone crops look like a phone; ultrawide looks wide. The whole page only appears as the small locator.

The takes

A · Slides

A short deck: the round in one line, then one slide per change, then what's next. Arrow keys or swipe.

Recommendation

Use C as the default proof in chat: the round in one glance, each change already cropped and marked. Tapping a tile opens the A slide for that change. Keep B for single, subtle changes where the movement is the point, like 16px onto a grid column.
