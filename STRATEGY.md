# Flyd Strategy

## Target problem

High-agency creative and technical work is blocked by weak framing, unclear priorities, and decisions made with incomplete evidence — not by a shortage of generated text. Current AI assistants answer prompts without understanding the larger work, leaving the user to transfer context and sustain project momentum manually.

## Our approach

Flyd wins by being a Mac-native intelligence layer that understands the larger work and closes the loop from judgment to verified progress, rather than by becoming a general-purpose agent platform. It grounds in current work, diagnoses the highest-leverage issue, intervenes with honest challenge, acts on approved steps, verifies outcomes, and compounds useful learning. Every interaction is judged against one question: did the user think better, produce stronger work, make meaningful progress, avoid a mistake, discover an opportunity, or retain learning that improves the future?

## Who it's for

**Primary:** High-agency knowledge workers whose output depends on judgment, taste, and decisions rather than repetitive task completion — and whose work spans multiple domains (strategy, design, writing, code, research). They're hiring Flyd to produce sharper thinking, stronger work, meaningful forward progress, and compounding capability they can feel week over week.

_George (founder) serves as the first user and validation case — a multidisciplinary entrepreneur, designer, creative technologist, and product builder working across several concurrent projects. The product must prove itself against his real work, but the persona it's designed for is anyone in this category._

## Key metrics

- **Accepted high-value interventions per active week** — interactions where the user confirms Flyd changed a decision, improved an artifact, exposed a missed issue, completed meaningful work, or preserved useful learning. Measured via voluntary-use logging.
- **Context accuracy** — correct active project and artifact identification. Target: ≥90%.
- **Artifact impact** — Flyd-generated or Flyd-directed revisions the user keeps.
- **Progress impact** — interactions resulting in a verified project-state change.
- **Time to useful output** — latency from invocation to first useful insight or action.

## Tracks

### Phase 0 — Establish the truth

Instrument current Flyd against real work to produce a baseline of where it loses to Clicky, generic chat, or manual work. Freeze unrelated architecture expansion.

_Why it serves the approach:_ The approach requires measuring whether interventions actually improve outcomes. Baseline truth is the prerequisite.

### Phase 1 — See and think

Natural voice/text conversation, screen-grounded answers, visual pointing and annotation, current project reconstruction, domain-aware critique, one high-leverage recommendation, session continuity.

_Why it serves the approach:_ The ground-diagnose-intervene loop requires Flyd to understand the immediate context and deliver honest, leveraged critique before it acts.

### Phase 2 — Improve and advance

Direct artifact revisions, bounded file and repository work, research and document creation, action preview and confirmation, verification and handoff.

_Why it serves the approach:_ Judgment without action leaves the user carrying the execution burden. This track converts diagnosis into verified progress.

### Phase 3 — Compound

Learn standards and recurring corrections, apply project decisions and rationale, detect repeated work patterns, selectively surface patterns during relevant work. A small roster of named specialists (starting with the coach) operates as a bounded compounding experiment on this loop — each specialist owns trigger-routed skills that learn from per-task retrospectives, user corrections, and evidence, the way a team compounds.

_Why it serves the approach:_ The compounding claim requires evidence that learning from prior interventions improves future ones. Specialists let different domains compound independently and measurably.

## Milestones

- **2026-08-08** — Seven-day founder gate: ten accepted high-value interventions, three materially improved artifacts, two projects advanced, three discovered issues/opportunities, ≥90% context accuracy, voluntary use on five of seven days, preference over Clicky for critique and generic chat for continuity.

## Not working on

- Gateway product, messaging channels, mobile companion, or everywhere-chat strategy
- General-purpose autonomous background assistant platform (a small roster of named specialists is a Phase 3 compounding experiment, not an agent platform)
- Broad SaaS integration catalogue, marketplace, or skill ecosystem
- Dynamic UI as default response mode
- Additional manifestation modes without a validated user need
- Memory sophistication without a measured product benefit
- Speculative proactive PRESENT cognition

## Marketing

**One-liner:** Flyd makes your work better and moves it forward.

**Key message:** Flyd understands the work in front of you, identifies what matters, improves it, helps execute the next meaningful step, and compounds what it learns about how you work.
