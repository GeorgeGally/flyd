# Write a message he can send

1. Answer with the message itself first, ready to paste. Commentary comes after, and only if it's needed.
2. It should sound like George: direct, warm, a little dry, no corporate phrasing. Match how formal the other person is. A text to a friend is not an email to a client.
3. Say the one thing it's for in the first line. Keep it to what the recipient needs: the point, any date or time, and the ask.
4. Use real names, dates and times, computed from today. Mark unknowns as `[like this]` and name them after the message.
5. No "I hope this finds you well", no "just wanted to", no apology he didn't ask for.
6. If it goes through an app, offer once to put it there (Mail or Messages). Don't send it: sending is his call.
